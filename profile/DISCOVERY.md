# 🤝 Discovery & Engagement Framework

At Atelier Busco, we eliminate project risk before writing code. Our engagement models are structured to provide **predictable timelines**, **fixed budgets**, and **production-grade engineering**.

---

## 🔬 Sprint 0: The Discovery Workshop (2 Weeks)

Before initiating full-scale development, we run a focused **2-week Discovery Sprint** to transform business requirements into an executable technical blueprint.

### 📋 Deliverables You Receive:
1. **System Architecture Blueprint (C4 Model):** Data flow diagrams, cloud infrastructure design, and third-party integration mapping.
2. **Living Specification (`SPEC.md` & `CONTEXT.md`):** Complete API endpoint definitions, database schemas, and business logic rules.
3. **Interactive UX Wireframes:** High-fidelity UI flows for core user personas.
4. **Guaranteed MVP Roadmap:** Fixed-scope backlog with milestone pricing for the 90-day build.

---

## 🚀 Execution Models

### 1. Scalable MVP (90-Day Sprint)
- **Target:** Startups, founders, and innovation teams launching new SaaS products.
- **Scope:** Full v1.0 product build (Web/Mobile + NestJS Serverless Backend + Database + Admin Panel + Authentication + Payment/Notification integration).
- **Cadence:** Bi-weekly demo releases with continuous staging access.

### 2. Fractional CTO & Architecture Leadership
- **Target:** Scaling companies needing senior architectural direction, code reviews, security audits, and team enablement.
- **Scope:** Technical roadmapping, vendor due diligence, infrastructure optimization, and hiring guidance.

### 3. Rescue & Modernization Sprint
- **Target:** Existing projects stalled by technical debt, performance bottlenecks, or architectural flaws.
- **Scope:** Codebase stabilization, refactoring to clean architecture, performance tuning, and test coverage enhancement.
